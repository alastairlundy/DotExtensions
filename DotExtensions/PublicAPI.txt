# DotExtensions public interface baseline (v11 surface reduction, ticket 004)
#
# WHAT THIS IS
#   A checked-in record of the public interface of the DotExtensions library after the
#   v11 surface-reduction changes, plus explicit records of deliberately deleted
#   members' absence (ledger T005: "baseline file records the full public interface
#   including intentionally internalized members' absence").
#
# SCOPE
#   Snapshot of the tree after tickets 001 (Dates deletions), 002 (WeekOfExtensions
#   reshape), and 005 (guard module merge). Ticket 005's deletions and internalizations
#   are recorded in the ABSENT section below (Ticket 005 block).
#
# FORMAT CONVENTION
#   T <full type name>                     public (exported) type
#     <signature>                          public member of the type above; members
#                                          declared inside C# 14 extension blocks are
#                                          shown in lowered static form - instance-style
#                                          members carry the receiver as the first
#                                          parameter, static members inside extension
#                                          blocks do not - with fully-qualified types,
#                                          parameter names and default values included;
#                                          extension properties are rendered as
#                                          Name(receiver) { get; }
#   ! <entry>                              ABSENT: a member/type deleted by the v11
#                                          reduction. It must never reappear; if a change
#                                          re-adds one of these, the baseline (and the
#                                          change) must be revisited deliberately.
#   PRESENT entries were produced by reflecting over the Release build of DotExtensions.dll
#   (net10.0) and cross-checked against the source tree's public type count (40 exported
#   public types / 40 unique simple names after ticket 005, matching exactly; 44/42 before
#   ticket 005 landed). ABSENT entries were reconstructed from git history (commits
#   dc0c6e3d, 04a24a94, 6bffda2d) and from ticket 005's pre-deletion source files, since
#   the members no longer exist in the binary.
#   To regenerate PRESENT: build Release, enumerate the assembly's exported types and
#   their public/protected members, and replace the PRESENT section below.
#   Note: signatures are metadata-level; reference-type nullability annotations (e.g.
#   String? parameters) are not recorded. Value-type nullability appears as Nullable<T>.
#
# ENFORCEMENT DECISION (ticket 004 open decision)
#   No enforcement mechanism is wired into the build or test gate; this file is a
#   reviewed record only. Trade-off vs. the ledger's candidates:
#     - PublicApiAnalyzers + PublicAPI.txt: the canonical build-time gate (RS0016/
#       RS0017), but adds a NuGet package against T030's "no new packages" pin, and
#       expresses removals only as analyzer suppressions rather than first-class
#       absence records like the "!" entries below (T005's constraint).
#     - ApiCompat golden-binary diff: needs a checked-in reference binary and cannot
#       express "this member must never return".
#     - TUnit reflection lock: no new packages, but couples the test suite to assembly
#       metadata and fails only at test time.
#   A record-only baseline satisfies T005's "record the full public interface including
#   removed members' absence" while leaving T030 untouched; wiring a gate remains open
#   as a follow-up (ticket 005's surface moves have since landed and are recorded above).
